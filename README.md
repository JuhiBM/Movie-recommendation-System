# 🎬 Movie Recommendation System

## 📌 Project Overview

The Movie Recommendation System is a machine learning-based application that recommends similar movies based on user selection.

The system analyzes movie information such as genres, keywords, cast, crew, and overview to find movies that are similar to the selected movie.

## 🚀 Features

- Search and select movies
- Get similar movie recommendations
- Content-based recommendation system
- Uses movie metadata for recommendations
- Interactive user interface

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- TMDB Dataset

## 🧠 How It Works

1. The movie dataset is loaded.
2. Movie information is processed and converted into features.
3. Similarity between movies is calculated.
4. When a user selects a movie, the system finds and recommends similar movies.
